# F2 / F2u fits of the data of each truth at 10, 20 and 30 dB (DESIGN 14, question iii)

Laplace fits of the n = 64 model (``scripts/parametric_snr.py``). z = (g_true - g_hat) / sd_Laplace. dPhi = Phi_MAP minus the misfit of the noise realization itself. p is P(Gamma(N - dim/2) >= Phi_MAP). c = dPhi / z^2 where the mean |z| is above 3. Under a correct model dPhi is about -dim/2 (-2.5 for F2) and p is uniform.
